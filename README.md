# 千机伞 · Myriad Umbrella

适用于原生 SillyTavern 与 Luker 的前端工具集，无后端插件或额外依赖。

在酒馆的“扩展 → 安装扩展”中填入仓库地址，安装后刷新页面：

```text
https://github.com/atonal519/ST-MyriadUmbrella
```

设置入口：插件抽屉 → **千机伞**。按需开启各项功能。

- **悬浮球收纳**：自由拖动；拖到左右边缘松手即收起，只露出 14px，以圆点标记入口。自由悬浮时为圆形，贴边后保留变窄和靠边轮廓，栏顶曲线与按钮轮廓配合。点击向下展开，长按管理；栏内原球横向拖出可解除收纳，停在松手处，上下滑动用于浏览。找不到时可在设置里点“显示收纳球”。支持点选添加、原球拖入和管理中移出。显示原来的球，不复制图标；统一为 32px 圆形显示并居中留白，栏内保留 36px 点击区域。大球居中裁切，小球等比填充。收起闲置时主球半透明；展开、按住、拖动或桌面悬停时完全不透明，展开期间底托和原球保持清晰。移出后恢复原球的尺寸、透明度及其余原样式。
- **QR 重生成与回退输入**：设置中勾选“在 QR 栏显示重生成和回退输入”，创建并启用原生“酒馆工具箱”集合。“重新生成”调用酒馆原生入口；“回退输入”撤回最后一条用户消息及其后回复，将用户原文放回空输入框，等待手动修改、发送。输入框有草稿或正在生成时不执行回退；带附件的用户输入请使用原生编辑。取消勾选隐藏本组按钮，保留内容，再次勾选复用原集合。勾选状态读取原生 QR 设置，打开工具箱不会自动写入 QR。
- **正文局部编辑**：电脑双击、手机三击文字，只打开点击或选中的局部原文。隐藏状态文字、Markdown 链接或楼内附加文案不要求整楼完全一致；无法准确定位时给出提示，不自动改成整楼编辑。修改同步正文、当前 swipe 与宿主消息事件。
- **通知外观**：仅“使用酒馆原样”和“顶部长细条”两种选择。长细条位于顶栏下方，两侧各留 8px、5px 圆角；底色和文字随酒馆主题变化，底色始终不透明。主题底色带透明度时，按正文深浅回退为黑底白字或白底黑字。保持原 Toastr 节点、按钮、链接、关闭与停留时间。

使用相应功能前，请关闭旧 toast 美化与“手机三击pc双击编辑 v1.1”，避免同时控制同一界面。旧插件和脚本不会被自动删除或修改。

早期本地版“酒馆工具箱”的设置、收纳清单和悬浮位置继续沿用；原生 QR 集合仍使用“酒馆工具箱”这个名称，避免重复创建或影响现有按钮。

复用来源：zmer-toast-theme-loader 的控件指纹、原球定位及恢复思路；绾绾原作、Sommer 二改的“手机三击pc双击编辑 v1.1”的手势、点击定位及格式归一思路。没有带入其全局弹窗样式、特定卡片关键词和提示文字工作流猜测。

开发验证：在酒馆安装目录的 `public/scripts/extensions/third-party/ST-MyriadUmbrella` 中运行 `npm test`，无需安装依赖。测试包含实际宿主 EventEmitter；可通过 `ST_UPSTREAM_REFERENCE=/path/to/SillyTavern npm test` 额外核对原生宿主参考代码。

另已在 Chromium 隔离页加载原生 SillyTavern / Luker 的实际 HTML、CSS、千千结原悬浮球模块、完整最近请求插件及原生 Toastr，检查收纳显示、点击、拖入/拖出与恢复、局部编辑和通知交互。QR 保存使用内存测试接口，隔离验证不等于实体手机或真实存档保存验收。
