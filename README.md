# 千机伞 · Myriad Umbrella

Android **0.2.1** 已正式发布：[下载安装包](https://github.com/atonal519/ST-MyriadUmbrella/releases/download/apk-v0.2.1/qianjisan-0.2.1.apk) · [源码与构建说明](android/README.md)。已有 0.1.6 及以上试用版可在 App 首页右上角检查更新，按系统提示覆盖安装。APK 与下方酒馆扩展分别更新。

当前前端插件版本：**0.1.1**。适用于原生 SillyTavern 与 Luker，无后端插件或额外依赖。

在酒馆的“扩展 → 安装扩展”中填入仓库地址，安装后刷新页面：

```text
https://github.com/atonal519/ST-MyriadUmbrella
```

打开入口：魔法棒菜单 → **千机伞**。魔法棒与收纳主球共用完整俯视伞面图标。主页底部只有 `char` 和“工具箱”两页，没有新增悬浮球入口。

- **char 卡库**：直接显示角色原图，首次默认使用普通两列，显示姓名与已知开场白数量，每批24张，点击“显示更多”继续浏览。顶部“切换”可选择普通两列／堆叠／错列，记住上次排版，关闭重开与刷新页面后继续使用。
- **艺术排版**：堆叠、错列每页分别展示6张或10张卡，上下滑动、滚轮或上下箭头整页浏览；不足一页时不补空卡，堆叠按本页实际图片组合居中。错列版按页轮换 January 至 December，保持酒馆原有角色顺序，不按创建日期分组。
- **伞面底纹**：三种卡库排版共用固定的钢笔排线伞角，翻页时底纹留在原位，随酒馆配色显示；阅读页与工具箱只保留细边框，角色原图不做处理。
- **开场白阅读**：支持名称搜索，点卡阅读默认和备选开场白，返回后保留浏览位置，不用创建聊天。复用酒馆已加载的角色数据；开启角色懒加载的宿主只补读当前卡。艺术排版只在可见页挂载卡图，以宿主缩略图占位，可见卡面加载原图，离开页面后释放对应图片节点。阅读页保留角色原图，正文默认不缩进、两端对齐，支持 Markdown 与静态 HTML，卡片自带样式优先；单独隔离排版，不执行脚本、宏或变量初始化；浏览不修改角色卡或聊天；只有手动切换排版时保存选择。
- **工具箱**：收纳和通知使用紧凑的折叠抽屉，QR、局部编辑、角色卡文件夹和随卡预设开关使用分隔开关行。主页配色跟随酒馆，背景保持不透明。

- **原生角色卡文件夹**：工具箱开启“角色卡文件夹”后，在酒馆原生角色管理列表显示自建抽屉，默认收起，点击同页展开；可新建、整理时改名、批量移动和删除分类。未归类角色进入“未分类”，删除文件夹只解散分类，保留角色卡。复用宿主完整的搜索/排序/标签筛选结果，包含原分页之外的角色；展开每批显示 24 张，沿用原生角色行、网格样式、标签和选卡入口。关闭后恢复宿主原有列表与分页，分类仍保存在千机伞设置里。千机伞自己的 char 卡库排版独立，不改变原生文件夹分类。
- **悬浮球收纳**：自由拖动；拖到左右边缘松手即收起，只露出 14px，以圆点标记入口。自由悬浮时为圆形，贴边后保留变窄和靠边轮廓，栏顶曲线与按钮轮廓配合。点击向下展开，长按管理；栏内原球横向拖出可解除收纳，停在松手处，上下滑动用于浏览。找不到时可在工具箱里点“显示收纳球”。支持点选添加、原球拖入和管理中移出。显示原来的球，不复制图标；统一为 32px 圆形显示并居中留白，栏内保留 36px 点击区域。大球居中裁切，小球等比填充。收起闲置时主球半透明；展开、按住、拖动或桌面悬停时完全不透明，展开期间底托和原球保持清晰。移出后恢复原球的尺寸、透明度及其余原样式。
- **同步状态**：启用收纳后独立监控 POST、PUT、DELETE 请求，进行中为黄色，全部结束后半秒转为空闲绿色；fetch 观察到响应头，XHR 观察到终止事件。自由悬浮时伞面变色，贴边时小圆点变色，只有窄光圈与轻微明暗变化。可停用或卸载原 Sync Monitor。
- **拉刻西斯预设球**：支持主酒杯、播放器及启用后的目录球收纳，保留原球与原面板。主酒杯和播放器复用酒馆助手已注册的面板入口；原预设脚本需保持启用。收起后不再按球的旧坐标截获正文点击，拖出恢复原样。
- **JM 阅读器浮球**：支持点选或拖入收纳，点击仍打开原阅读器，最小化后原球回到收纳栏。横向拖出后继续使用 JM 原有的位置保存。
- **QR 重生成与回退输入**：工具箱分别勾选“QR 重新生成”和“QR 回退输入”，可以只显示其中一个，使用原生“千机伞”集合。旧版“酒馆工具箱”在升级时更名，保留按钮、显示状态和 QR 助手白名单。“重新生成”调用酒馆原生入口；“回退输入”撤回最后一条用户消息及其后回复，将用户原文放回空输入框，等待手动修改、发送。输入框有草稿或正在生成时不执行回退；带附件的用户输入请使用原生编辑。取消各自开关只隐藏对应按钮，保留内容，其他按钮保持原样。勾选状态读取原生 QR 设置，打开工具箱不会自动写入 QR。
- **正文局部编辑**：电脑双击、手机三击文字，默认打开点击处的完整段落，包含同段对白与内联格式；手动选中文字后按选区编辑。隐藏状态文字、Markdown 链接或楼内附加文案不要求整楼完全一致；无法准确定位时给出提示，不自动改成整楼编辑。修改同步正文、当前 swipe 与宿主消息事件。
- **随卡保存预设开关**：工具箱开启后，角色卡“更多”菜单出现“保存当前预设开关”和“清除已保存开关”；关闭后移除菜单选项。点击保存才把当前对话补全预设的条目开关写入这张卡，按预设名称分别保留。进入该角色并使用对应预设时恢复，未保存的卡沿用原预设开关，新条目沿用预设默认值；正文、顺序与模型参数不复制。清除只移除当前卡当前预设的快照。Luker 使用其原生整份卡绑定预设时，继续由宿主保存。
- **通知外观**：仅“使用酒馆原样”和“顶部长细条”两种选择。长细条位于顶栏下方，电脑端居中、最大宽 560px，手机端两侧各留 8px，统一 5px 圆角；底色和文字随酒馆主题变化，底色始终不透明。主题底色带透明度时，按正文深浅回退为黑底白字或白底黑字。保持原 Toastr 节点、按钮、链接、关闭与停留时间。

使用相应功能前，请关闭旧 toast 美化与“手机三击pc双击编辑 v1.1”，避免同时控制同一界面。旧插件和脚本不会被自动删除或修改。

早期本地版“酒馆工具箱”的设置、收纳清单和悬浮位置继续沿用；原生 QR 集合在升级时更名为“千机伞”，保留原集合内容、显示状态、原生 QR 绑定与 QR 助手白名单和分栏偏好。

复用来源：zmer-toast-theme-loader 的控件指纹、原球定位及恢复思路；绾绾原作、Sommer 二改的“手机三击pc双击编辑 v1.1”的手势、点击定位及格式归一思路；wominIII/Sync-Monitor 的请求计数与空闲延迟逻辑（MIT，见 [许可证](licenses/sync-monitor.txt)）。没有带入其全局弹窗样式、特定卡片关键词和提示文字工作流猜测。

安装用户直接使用仓库内的 `src/runtime.bundle.js`，无需构建。维护时继续修改 `index.js` 与 `src` 下的分模块源码，再运行 `npm run build` 更新单一启动产物；构建使用 webpack，安装在酒馆扩展目录内时可复用宿主已有依赖。字体和图片继续独立加载，不打进脚本。

开发验证：在酒馆安装目录的 `public/scripts/extensions/third-party/ST-MyriadUmbrella` 中运行 `npm test`，无需安装依赖。测试包含实际宿主 EventEmitter；可通过 `ST_UPSTREAM_REFERENCE=/path/to/SillyTavern npm test` 额外核对原生宿主参考代码。

另已在 Chromium 隔离页加载原生 SillyTavern / Luker 的实际 HTML、CSS、千千结原悬浮球模块、完整最近请求插件及原生 Toastr，检查收纳显示、点击、拖入/拖出与恢复、局部编辑和通知交互。分类整理、原生“更多”菜单分发、实际 PromptManager 的开关处理与启用条目消费者也已覆盖。QR 使用内存测试接口，条目保存使用临时 HTTP 存储与宿主合并函数；隔离验证不等于实体手机或真实存档保存验收。
